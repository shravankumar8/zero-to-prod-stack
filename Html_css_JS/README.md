# HTML CSS JavaScript Tutorial Playbook

This project is a hands-on revision website for:

- HTML fundamentals + semantic markup + forms + media + SEO basics
- CSS selectors + box model + layout systems + responsiveness + best practices
- JavaScript fundamentals + async + DOM APIs + modules + memory + debugging

## Run

Open `index.html` in your browser.

Optional local server:

```bash
python3 -m http.server 5500
```

Then open <http://localhost:5500>.

## How to use

1. Start at **Web Foundations**.
2. Expand each track section and tick topics as you revise.
3. Use **Practice Lab** to test HTML, CSS, and JavaScript concepts.
4. Continue using roadmap links for deeper coverage.

## Notes

- Topic checkboxes are saved in browser local storage.
- Content is designed as fast revision + practical reinforcement.
